В проекте применены тесты для проверки работоспособности сервиса для сборки
и заказа бургеров из необычных ингредиентов.
https://stellarburgers.education-services.ru/

Тесты содержат следующие проверки:

Регистрация
1. успешная регистрация
2. ошибка для некорректного пароля

Вход
3. вход по кнопке «Войти в аккаунт» на главной
4. вход через кнопку «Личный кабинет»
5. вход через кнопку в форме регистрации
6. вход через кнопку в форме восстановления пароля

Переход в личный кабинет
7. переход по клику на «Личный кабинет»

Переход из личного кабинета в конструктор
8. переход по клику на «Конструктор»
9. переход по клику на логотип Stellar Burgers

Выход из аккаунта
10. выход по кнопке «Выйти» в личном кабинете

Раздел «Конструктор»
11. переход к разделу «Булки»
12. переход к разделу «Соусы»
13. переход к разделу «Начинки»

Для работы применены фикстуры в файле conftest.py.

Требования: Python 3.7+, библиотеки: Selenium, pytest, Faker,
браузер Google Chrome, совместимый ChromeDriver (подгружается автоматически через Selenium Manager).

Установка зависимостей:
pip install selenium pytest faker

Запуск всех тестов:
python -m pytest tests/ -v
